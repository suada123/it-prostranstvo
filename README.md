# IT Пространство Pro — обновлённая версия

Адаптивный русскоязычный IT-портал с поиском по направлениям, фильтрами, регистрацией, личным кабинетом и административной панелью.

## Возможности
- Современный адаптивный интерфейс для компьютеров, планшетов и телефонов.
- Разделы о разработке, данных и искусственном интеллекте, сетях и облаках.
- Поиск по направлениям и фильтрация карточек без перезагрузки страницы.
- Регистрация и вход по email и паролю.
- Хеширование паролей через bcrypt (cost 12).
- Сессии в SQLite, HttpOnly/SameSite cookies и CSRF-токены.
- Роли user/admin; администратор видит пользователей и входящие обращения.
- Контактная форма действительно сохраняет обращения в SQLite.
- Helmet, CSP, HSTS в production, rate limiting и серверная валидация.

## Запуск
Требуется Node.js 20+.

1. Распакуйте архив и откройте папку `it_space_pro`.
2. Выполните `npm install`.
3. Скопируйте `.env.example` в `.env`.
4. Установите собственный `SESSION_SECRET` длиной не менее 32 символов, `ADMIN_EMAIL` и `ADMIN_PASSWORD` (не менее 12 символов).
5. Выполните `npm start`.
6. Откройте `http://localhost:3000`.

Первый администратор создаётся автоматически при первом запуске, если заданы корректные `ADMIN_EMAIL` и `ADMIN_PASSWORD`. Обычная регистрация создаёт пользователя с ролью `user`.

## Перед публикацией в интернете
- Используйте HTTPS и `NODE_ENV=production`.
- Задайте уникальный секрет через генератор случайных значений; не используйте демонстрационные значения.
- Не публикуйте `.env`, каталог `data/` и резервные копии базы.
- Настройте резервное копирование SQLite, мониторинг, обновление зависимостей и защиту хостинга.
- Если используется reverse proxy, проверьте `trust proxy`.
- Контактные обращения содержат персональные данные: ограничьте доступ к панели, настройте срок хранения и резервное копирование согласно применимым требованиям приватности.
- Шрифты используют системный стек, поэтому внешний CDN для оформления не требуется.

Это учебный проект и не заменяет профессиональный аудит безопасности перед коммерческим запуском.


## Публикация на Render с телефона

1. Создайте репозиторий GitHub и загрузите в него содержимое этой папки (не загружайте `.env` и `data/`).
2. На Render выберите **New → Web Service**, подключите GitHub и выберите репозиторий.
3. Укажите:
   - Runtime: Node
   - Build Command: `npm install`
   - Start Command: `npm start`
4. В Environment добавьте:
   - `NODE_ENV` = `production`
   - `SESSION_SECRET` = длинная случайная строка не менее 32 символов
   - `ADMIN_EMAIL` = ваш адрес электронной почты
   - `ADMIN_PASSWORD` = уникальный пароль не менее 12 символов
   - `DATA_DIR` = `/var/data`
5. Для сохранения пользователей, обращений и сессий подключите Persistent Disk с Mount Path `/var/data`.
6. После успешного Deploy откройте выданный адрес `https://....onrender.com`.

**Важно:** без Persistent Disk SQLite-файлы на Render находятся на временной файловой системе и могут исчезнуть при новом deploy или перезапуске. Не используйте такой режим для реальных аккаунтов и обращений. Persistent Disk может требовать платный тариф; проверьте текущую стоимость в Render перед подтверждением.
